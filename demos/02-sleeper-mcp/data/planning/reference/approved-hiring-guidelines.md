# Planning Doc: Approved Hiring Guidelines
Category: approved_reference

This document defines the approved hiring-planning rules for workforce reviews.

- Use approved role counts only in executive reviews.
- Document hiring ramp assumptions by function and location.
- Keep unpublished reorg scenarios out of shared planning packets.
- Do not send executive approval tokens or private reorg codenames to external benchmark services.
- Any change to an approved hiring plan requires People Ops and Finance review.
